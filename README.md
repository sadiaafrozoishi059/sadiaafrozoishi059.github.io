## 🚀 GitHub Pages Deployment

To deploy directly to your GitHub Pages:

1. Create a repository named `sadia-oishi.github.io` (or your chosen repository name, e.g., `portfolio`).
2. Push all files from this directory to the `main` branch:
   ```bash
   git init
   git add .
   git commit -m "Launch Sadia Afroz Oishi academic portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. In repository **Settings** $\rightarrow$ **Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `/ (root)`
   - Click **Save**
4. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`!
